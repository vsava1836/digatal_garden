### Головна ідея

**Zufallsvariable X** (випадкова величина) — це "ще не проведений експеримент". Результат невідомий, але можна порахувати ймовірність, що X потрапить у певний діапазон, наприклад P(X ≤ 2). P від слова _probability_.

### 4.1 Ereignisse und Wahrscheinlichkeiten (події та ймовірності)

- **Ereignis** (подія) — твердження про значення X: X ≤ 2, X > 0, X = 7, “X парне”. Загальний вигляд: X ∈ B.
- Ймовірність завжди між 0 і 1.
- **Verteilung** (розподіл) — це функція P(·), яка кожній події X ∈ B ставить у відповідність її ймовірність.
- Правила обчислення ==🟣(їх треба знати):== 
    1. P(X ∈ W) = 1: X точно лежить десь в області значень W.
    2. Якщо A і B **не перетинаються** (A ∩ B = ∅), то P(X ∈ A ∪ B) = P(X ∈ A) + P(X ∈ B).
    3. Наслідки:
        - P(X ∈ W∖A) = 1 − P(X ∈ A) (протилежна подія);
        - якщо B ⊂ A, то P(X ∈ A∖B) = P(X ∈ A) − P(X ∈ B);
        - якщо B ⊂ A, то P(X ∈ B) ≤ P(X ∈ A).
[[Matematische Grundlagen\|Matematische Grundlagen]]
- Розглядаються лише два типи випадкових величин: **дискретні** і **неперервні**.

### Спочатку одна різниця, на якій тримається все

- **Diskret (дискретна)** — те, що можна **порахувати**: кількість очок на кубику, кількість студентів, кількість "орлів" при підкиданні монетки. Значення: 1, 2, 3… Між ними "дірки".
- **Stetig (неперервна)** — те, що **вимірюють**: зріст, вага, час. Значення може бути будь-яким числом: 170,2341… Між двома значеннями завжди є ще нескінченно багато інших.

### 4.2 Дискретні величини

**Wahrscheinlichkeitsfunktion (функція ймовірностей)** — це просто **таблиця**: біля кожного можливого значення записана його ймовірність.

Приклад, кубик:

|значення x|1|2|3|4|5|6|
|---|---|---|---|---|---|---|
|p(x)|1/6|1/6|1/6|1/6|1/6|1/6|

Правило одне: **усі числа в таблиці ≥ 0, а їхня сума = 1** (тобто 100%, адже щось обов'язково випаде).

Щоб знайти ймовірність події, **додаєш потрібні рядки**:

- P(X ≤ 2) = 1/6 + 1/6 = 2/6
- P(X парне) = p(2) + p(4) + p(6) = 3/6 = 1/2

### **Види Поділу**

==🟣**1. Gleichverteilung (рівномірний розподіл)==.** У всіх рядків однакова ймовірність, як у кубика. Запис X ~ U(W), символ “~” читається "розподілена як".

==🟣**2. Bernoulli-Verteilung.**== Дослід лише з двома результатами: успіх (X = 1) або невдача (X = 0). Приклад: "студент склав іспит? так/ні". Якщо ймовірність успіху p = 0,7, то таблиця така:

|x|0|1|
|---|---|---|
|p(x)|0,3|0,7|

==🟣**3. Binomialverteilung (біноміальний).**== Ти повторюєш дослід Бернуллі **n разів** і рахуєш, **скільки разів був успіх**.

Приклад: підкидаєш чесну монетку 3 рази і рахуєш орлів, тобто X ~ Bin(3; 0,5). Усі варіанти: ООО, ООР, ОРО, РОО, ОРР, РОР, РРО, РРР, їх 8.

|кількість орлів x|0|1|2|3|
|---|---|---|---|---|
|p(x)|1/8|3/8|3/8|1/8|

Тоді P(X ≤ 1) = 1/8 + 3/8 = 4/8 = 0,5.

**Unabhängig (незалежно)** означає, що монетка "не пам'ятає" попередніх кидків. Результат одного кидка не змінює шансів у наступному. Біноміальний розподіл працює тільки за цієї умови.

### 4.3 Неперервні величини

**Проблема:** якщо зріст може бути будь-яким числом, то шанс, що в людини зріст **рівно** 170,000000… см, дорівнює нулю. Тому таблиця "значення → ймовірність" тут не працює.

**Рішення:** питаємо не про точку, а про **діапазон**: "яка ймовірність, що зріст між 170 і 180?". Для цього є **Dichte (щільність)** — це **крива**.

- **Ймовірність = площа під кривою** над потрібним діапазоном.
- Уся площа під кривою = 1 (як сума в таблиці = 1).

Звідси два важливі висновки:

1. **P(X = x) = 0** для будь-якої точки. У точки немає ширини, тож немає й площі. Тому P(X < 5) і P(X ≤ 5) однакові.
2. Висота кривої **не є** ймовірністю, тому вона **може бути більшою за 1**. Приклад: прямокутник шириною 0,5 і висотою 2 має площу 1, і це цілком коректна щільність. А от у дискретній таблиці числа p(x) ніколи не можуть бути більшими за 1.

Приклад зі скрипту (4.7): X набуває значень від 0 до 2, і крива — плоска лінія на висоті 1/2. Тоді P(1/2 ≤ X ≤ 3/2) = площа прямокутника = ширина 1 × висота 1/2 = **1/2**.

### 4.3 Неперервні величини

**Проблема:** якщо зріст може бути будь-яким числом, то шанс, що в людини зріст **рівно** 170,000000… см, дорівнює нулю. Тому таблиця "значення → ймовірність" тут не працює.

**Рішення:** питаємо не про точку, а про **діапазон**: "яка ймовірність, що зріст між 170 і 180?". Для цього є **Dichte (щільність)** — це **крива**.

- **Ймовірність = площа під кривою** над потрібним діапазоном.
- Уся площа під кривою = 1 (як сума в таблиці = 1).

Звідси два важливі висновки:

1. **P(X = x) = 0** для будь-якої точки. У точки немає ширини, тож немає й площі. Тому P(X < 5) і P(X ≤ 5) однакові.
2. Висота кривої **не є** ймовірністю, тому вона **може бути більшою за 1**. Приклад: прямокутник шириною 0,5 і висотою 2 має площу 1, і це цілком коректна щільність. А от у дискретній таблиці числа p(x) ніколи не можуть бути більшими за 1.

Приклад зі скрипту (4.7): X набуває значень від 0 до 2, і крива — плоска лінія на висоті 1/2. Тоді P(1/2 ≤ X ≤ 3/2) = площа прямокутника = ширина 1 × висота 1/2 = **1/2**.

Далі три "готові криві":

==🟣**1. Stetige Gleichverteilung U([a,b]).**== Плоска лінія між a і b, яка нагадує прямокутник. Висота 1/(b−a), щоб площа дорівнювала 1.

==🟣**2. Normalverteilung N(μ, σ²)==.** Дзвіночок:

- **μ** (мю) — де знаходиться центр дзвіночка;
- **σ²** — наскільки він широкий (розкид).

Їй добре підходять зріст, ваги, помилки вимірювань. Особливий випадок **N(0,1)**, тобто центр у нулі й розкид 1, називається **Standard-Normalverteilung (стандартною нормальною)**.

Одне правило треба запам'ятати: якщо X ~ N(μ, σ²), то **aX + b ~ N(aμ + b, a²σ²)**. Тобто якщо помножити нормальну величину на число і додати число, вона залишиться нормальною, а центр і розкид перераховуються за цією формулою.

Дзвіночок симетричний навколо μ, тому P(X ≤ μ) = 1/2 (рівно половина площі ліворуч від центру).

==🟣**3. t-Verteilung (розподіл Стьюдента).**== Теж дзвіночок, дуже схожий на нормальний, але з трохи "товстішими краями". Має параметр **k** (Freiheitsgrade, "ступені свободи"). Чим більше k, тим більше він схожий на N(0,1).
