## Головна ідея розділу

Дані та випадкові величини «багатовимірні». Вектор даних із n чисел є точкою в n-вимірному просторі. Розподіл (Verteilung) неперервної величини описується функцією щільності, тобто «нескінченновимірним вектором». Людині це важко уявити. Тому ми описуємо дані простішими засобами. Частина інформації при цьому губиться, але якщо це неважлива інформація, ми краще бачимо суть.

У розділі три інструменти:

1. функція розподілу (Verteilungsfunktion),
2. квантильна функція (Quantilfunktion),
3. діаграма розмаху, «ящик з вусами» (Box-Diagramm).

Кожен з перших двох існує у двох версіях: для випадкових величин (теорія) і для даних (емпіричний варіант).

### 5.1 Функція розподілу (Verteilungsfunktion)

**Означення:** F(t) = P(X ≤ t). Це ймовірність того, що X не перевищить t.
- ==🟣**F(t)** відповідає на питання: «яка ймовірність, що випадкове число **не більше за t**?»==


**Корисні формули:**

- P(X > t) = 1 − F(t)
- P(a < X ≤ b) = F(b) − F(a)

**Дискретна випадкова величина:**

- F(t) є сумою: F(t) = Σ p(x) за всіма x ≤ t.
- Графік схожий на сходи. Це Treppenfunktion (сходова функція). Між можливими значеннями F стала, а в точках, де p(t) > 0, вона стрибає вгору.

**Неперервна випадкова величина:**

- F(t) є інтегралом щільності: F(t) = ∫ f(x) dx від −∞ до t.
- Стрибків немає. Якщо F диференційовна, то F′(t) = f(t).

**Важливо:** функція розподілу описує розподіл без втрати інформації. Дві випадкові величини мають однаковий розподіл тоді і тільки тоді, коли їхні функції розподілу збігаються.

**Приклади, які скрипт розглядає:**

- дискретний рівномірний розподіл на {1,…,m}: F(t) = ⌊t⌋/m, тобто ціла частина від t, поділена на m;
- Бернуллі: F(t) = 0 при t < 0, 1−p при 0 ≤ t < 1, 1 при t ≥ 1;
- біноміальний: сума біноміальних ймовірностей (спростити не можна);
- неперервний рівномірний на [ a, b ]: F(t) = (t−a)/(b−a) для a ≤ t ≤ b;
- нормальний: позначається Φ(t) для стандартного N(0,1); інтеграл не обчислюється у закритому вигляді, тому використовують таблиці або комп'ютер;
- t-розподіл: те саме, F_k(t) → Φ(t) при k → ∞.

### 5.1.2 Емпірична функція розподілу (empirische Verteilungsfunktion)

Для вектора даних x = (x₁,…,xₙ):

**F̂(t) = (кількість xᵢ ≤ t) / n.** Це частка значень, що не перевищують t.

**Як рахувати:**

1. Впорядкувати значення за зростанням: x₍₁₎ ≤ x₍₂₎ ≤ … ≤ x₍ₙ₎. Це Ordnungsstatistiken (порядкові статистики), де x₍₁₎ найменше, а x₍ₙ₎ найбільше.
2. Подивитись, де t лежить відносно них: F̂(t) = 0 при t < x₍₁₎, F̂(t) = i/n при x₍ᵢ₎ ≤ t < x₍ᵢ₊₁₎, F̂(t) = 1 при t ≥ x₍ₙ₎.

**Третя формула** використовує Indikator-Funktion (індикаторну функцію) 1{xᵢ ≤ t}, яка дорівнює 1, якщо умова виконана, і 0 в іншому випадку. Тоді F̂(t) = (1/n) · Σ 1{xᵢ ≤ t}.

**Властивості:**

- значення від 0 до 1;
- це сходова функція, яка або стала, або стрибає вгору;
- висота стрибка в точці дорівнює (кількість повторів цього значення)/n;
- порядок значень у векторі не впливає на F̂, тому інформація про порядок втрачається.

**Приклад зі скрипту (5.7 і 5.9).** Дані (8,7,3,3,2,3,2,8), n = 8. Впорядковані: (2,2,3,3,3,7,8,8).

|значення wᵢ|абс. частота h|відн. частота p|F̂(wᵢ)|
|---|---|---|---|
|2|2|2/8|2/8|
|3|3|3/8|5/8|
|7|1|1/8|6/8|
|8|2|2/8|8/8|

Перевірка за таблицею: F̂(4) = 5/8, бо чотирьох точок, що ≤ 4, п'ять (2,2,3,3,3).

### 5.2 Квантильна функція (Quantilfunktion)

**Означення:** Q(α) = min{ t : F(t) ≥ α }, для 0 < α < 1.

- ==🟣**Q(α)** відповідає на питання навпаки: «яке число t треба взяти, щоб ймовірність бути не більше за нього дорівнювала α?»==

Тобто це найменше t, при якому F(t) досягає рівня α. Це «обернена функція» до функції розподілу.

**Навіщо потрібне означення через min:** F не завжди має обернену функцію, наприклад, коли вона сходова. Тоді Q(α) підбирається так, щоб F(Q(α)) було близьке до α.

**Два випадки:**

- F неперервна: F(Q(α)) = α.
- F не неперервна: F(Q(α)) дорівнює α або принаймні близьке до α.
- Якщо обернена функція F⁻¹ існує, то Q = F⁻¹. Наприклад, для стандартного нормального розподілу Q(α) = Φ⁻¹(α).

**α-квантиль** це значення Q(α). Особливі квантилі мають власні назви:

|α|Q(α)|Назва німецькою|Назва українською|
|---|---|---|---|
|0.1|Q(0.1)|Dezil|перший дециль|
|0.25|Q(0.25)|unteres Quartil|нижній квартиль|
|0.5|Q(0.5)|Median|медіана|
|0.75|Q(0.75)|oberes Quartil|верхній квартиль|
|0.9|Q(0.9)|neuntes Dezil|дев'ятий дециль|

_(У скрипті в рядку про верхній квартиль через помилку розпізнавання тексту мені видно «Q(0.25)», але це має бути Q(0.75).)_

### 5.2.2 Емпіричні квантилі (empirische Quantilfunktion)

Означення те саме, лише F замінюється на F̂: Q̂(α) = min{ t : F̂(t) ≥ α }.

**Формула через порядкові статистики:**  
**Q̂(α) = x₍ᵢ₎, якщо (i−1)/n < α ≤ i/n,** або, що те саме, i−1 < nα ≤ i.

**Практично:** порахувати nα, округлити вгору до цілого i і взяти i-те за величиною значення.

**Приклад (5.11)**, n = 8, дані (2,2,3,3,3,7,8,8):

|α|nα|i|Результат|
|---|---|---|---|
|0.25|2|2|x₍₂₎ = 2|
|0.5|4|4|x₍₄₎ = 3|
|0.75|6|6|x₍₆₎ = 7|
|0.9|7.2|8|x₍₈₎ = 8|

Зверни увагу: якщо nα ціле, береться саме це значення. Наприклад, nα = 4 дає x₍₄₎, а не середнє між x₍₄₎ і x₍₅₎. Якщо nα не ціле, округлюємо вгору.

### 5.2.3 Діаграма розмаху, «ящик з вусами» (Box-Diagramm / Box-Plot)

Візуалізація даних, побудована на квантилях.

**Складові:**

- **Box (ящик):** нижній край дорівнює Q(0.25), верхній край дорівнює Q(0.75), товста лінія всередині дорівнює медіані Q(0.5).
- **Interquartilabstand, IQR (міжквартильний розмах):** IQR = Q(0.75) − Q(0.25).
- **Antennen (вуса):**
    - верхній вус закінчується на найбільшій точці даних, що **не перевищує** Q(0.75) + 1.5·IQR;
    - нижній вус закінчується на найменшій точці даних, що **не менша за** Q(0.25) − 1.5·IQR.
- **Ausreißer (викиди):** усі точки поза цим інтервалом позначаються окремими крапками.

Горизонтальна вісь нічого не означає, ширина ящика довільна. Важливі лише вертикальні координати. Діаграму іноді малюють «лежачою» (осі поміняні), а множник 1.5 іноді замінюють іншим.

**Приклад (5.12):** Q(0.25) = 2, Q(0.5) = 3, Q(0.75) = 7, тож IQR = 5.

- верхня межа: 7 + 7.5 = 14.5, найбільша точка ≤ 14.5 це 8, тому верхній вус закінчується на 8;
- нижня межа: 2 − 7.5 = −5.5, найменша точка ≥ −5.5 це 2, і вона збігається з нижнім краєм ящика, тому нижнього вуса немає;
- викидів немає.
