### Головна думка

Мета статистики: за **спостереженими** об'єктами дізнатися щось про **неспостережені**. Наприклад, спрогнозувати завтрашню погоду, ціну акцій чи результат виборів. Усе, що ми спостерігаємо, називається **statistisches Experiment** («статистичний експеримент»).

===================

|            | Ще не проведено (результат невідомий) | Уже проведено (результат відомий) |
| ---------- | ------------------------------------- | --------------------------------- |
| назва      | Zufallsvariable                       | Daten / Datenpunkt                |
| позначення | **великі** літери: X                  | **малі** літери: x                |

====================
**Wertebereich** (область значень) буває двох типів:

- **diskret** («дискретна»): значень скінченна або зліченна кількість, їх можна перелічити (кількість братів і сестер, натуральні числа ℕ).
- **kontinuierlich** («неперервна»): значень «незліченно багато», як на числовій прямій ℝ (температура).

Nominalskala+Ordinalskala= qualitative skalen (якісні/дискретні)
Intervallskala+ Verhaltnisskala= quantative Skalen (кількісні/неперервні)

*в температури нуль умовний, в ваги нуль чіткий*
