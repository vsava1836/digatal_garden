## Kapitel 1

1. **Статистика** це вміння правильно інтерпретувати дані. Інструменти: здоровий глузд, математика (як мова), комп'ютер (R).
2. **Зв'язок ≠ причина.** Якщо дві величини змінюються разом (Zusammenhang), це ще не означає, що одна викликає другу (ursächlicher Zusammenhang). Приклади: вбивства vs Internet Explorer, освіта vs тривалість життя. У тестах правильна відповідь майже завжди «видно зв'язок», а не «причина».
3. **Читаючи діаграму, перевір, що є 100%.** У Beispiel 1.2 відсотки стосуються лише **госпіталізованих** дітей, а не всіх дітей. Сума 5,2 + 14,7 + 17 + 21,5 + 21,7 = 80,1%.
4. **Відсотки та відсоткові пункти.** Різниця 15 п.п. не те саме, що «на 200% більше». Дивись, віднімали чи ділили (це ключ до завдання 1, його я не бачила).
5. **Σ** це додавання, **Π** це множення. Σᵢ₌₁⁵ i² = 55, Πᵢ₌₁⁵ i = 5! = 120. Рахуй кількість доданків уважно: у Σᵢ₌₋₃³ їх 7, а не 6.
6. **Вектор і середнє:** x = (x₁, …, xₙ)′, ι = (1, …, 1)′. Тоді ι′x = Σ xᵢ, середнє x̄ = (1/n)·ι′x.
7. **Сума квадратів:** x′x = Σ xᵢ² = ‖x‖² (довжина в квадраті). Тому (1/n) Σ xᵢ² = ‖x‖²/n.
8. **Не плутай:** x′y це **число** (скалярний добуток), xy′ це **матриця**. Приклад: x′y = 3 + 8 + 15 = 26.
9. **Сума відхилень від середнього = 0:** Σ(xᵢ − x̄) = nx̄ − nx̄ = 0. Ключ у тому, що x̄ це константа, тому Σ x̄ = n·x̄.
10. **Похідна та інтеграл:** не забувай кожен доданок (d/dx(x³+2x²+x) = 3x²+4x**+1**). У скрипті інтеграл пишуть без «+c».
11. **Домовленості скрипта:** округлення до 2 знаків, десяткова **крапка** (0.5), тисяча як 1,000.
12. **Грецькі літери:** Σ (sigma), Π (pi), τ (tau), α (alpha), ι (iota), κ (kappa). Ними позначають невідомі величини, які оцінюють за даними.
13. **Мета курсу:** розуміти, як працюють методи, де їхні сильні та слабкі сторони. Застосувати метод у R легко, але без розуміння це дає хибні висновки.

## Kapitel 2

1. **Zufallsvariable** — це експеримент, який ще не відбувся. **Ereignis** (подія) — це умова на її значення: X ≤ 2, X > 0, X ∈ B. Ймовірність події лежить між 0 і 1.
2. **Два базові правила:** P(X ∈ W) = 1, а якщо A і B не перетинаються, то P(A ∪ B) = P(A) + P(B).
3. **Наслідки правил (часто в завданнях):**
    - P(доповнення A) = 1 − P(A).
    - Якщо B ⊂ A, то P(A \ B) = P(A) − P(B).
    - Якщо B ⊂ A, то P(B) ≤ P(A).
    - Загальна формула: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
4. **Дискретна:** є Wahrscheinlichkeitsfunktion p(x) (таблиця). Усі p(x) від 0 до 1, а сума всіх p(x) = 1. Ймовірність події дорівнює сумі p(x) по значеннях з події. Перевірка, чи це взагалі функція ймовірностей: немає від'ємних чисел і сума = 1.
5. **Неперервна:** є Dichtefunktion f(x) (крива). Вона невід'ємна, а площа під нею = 1. Ймовірність події дорівнює площі під кривою над відповідною областю.
6. **Точкова ймовірність:**
    - Для дискретної P(X = x) = p(x).
    - Для неперервної P(X = x) = 0 завжди.
    - Тому для неперервної P(X < t) = P(X ≤ t), а для дискретної ці числа можуть відрізнятися.
7. **Межі:** p(x) ≤ 1 завжди, але щільність f(x) може бути більшою за 1. Наприклад, f(x) = 3x² на [0, 1] має f(1) = 3. Обмежена лише площа (= 1), а не висота.
8. **Три дискретні розподіли:**
    - **U(W)** (Gleichverteilung, рівномірний): p(x) = 1/m, як у чесного кубика.
    - **B(p)** (Bernoulli): два результати, p(1) = p, p(0) = 1 − p.
    - **Bin(n, p)** (Binomial): кількість успіхів у n **незалежних** спробах, p(k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ для k = 0…n.
9. **Зв'язки між розподілами:** Bin(1, p) — це те саме, що B(p). B(1/2) = U({0, 1}). Але Bin(n, 1/2) **не** рівномірний при n ≥ 2: найімовірніші значення посередині.
10. **Рахунок для Bin:** P(X ≤ k) — це сума p(0) + … + p(k). Для Bin(3; 0,5) маємо P(X ≤ 2) = 1 − p(3) = 1 − 0,125 = 0,875. Часто швидше рахувати через доповнення.
11. **Нормальний розподіл N(μ, σ²):** μ — центр, σ² — розкид (дисперсія). Крива симетрична відносно μ, тому P(X ≤ μ) = 1/2. N(0, 1) — **Standard-Normalverteilung**, її щільність позначають φ.
12. **Лінійні перетворення:**
    - μ + σZ ~ N(μ, σ²), якщо Z ~ N(0, 1).
    - aX + b ~ N(aμ + b, a²σ²), якщо X ~ N(μ, σ²). Дисперсія множиться на **a²**, а не на a.
13. **Неперервна рівномірна U([a, b]):** f(x) = 1/(b − a) на [a, b]. Якщо Z ~ U([0, 1]), то a + (b − a)Z ~ U([a, b]).
14. **t-Verteilung з k Freiheitsgraden** (ступенями свободи): схожа на N(0, 1), але з «важчими хвостами». При k → ∞ наближається до N(0, 1). Використовується в Konfidenzintervallen і Hypothesentests (пізніші розділи).
15. **Наближення:** при великому n розподіл Bin(n, p) стає схожим на нормальний і «стискається» навколо середнього. Це підготовка до центральної граничної теореми (розділ 7).
16. **Типовий розрахунок щільності:** знайти невідому константу з умови ∫f = 1 (наприклад, f = c·sin(x) на [0, π]: інтеграл = 2, тому c = 1/2), а потім ймовірність як площу. Приклад: для f = 3x² на [0, 1] маємо P(X ≤ 1/2) = (1/2)³ = 1/8.
## Kapitel 3

1. **Який графік для чого.** Одна величина з небагатьма різними значеннями: Balkendiagramm або Kreisdiagramm. Одна величина з багатьма значеннями: Histogramm. Дві величини: Streudiagramm. Якщо значення цілі й повторюються: Jitter-Diagramm.
2. **Balkendiagramm:** висота стовпчика дорівнює частоті значення. Сума відносних частот дорівнює 1, сума абсолютних дорівнює n (довжині вектора).
3. **Порядок значень у векторі не впливає на Balkendiagramm.** Вектори x і y з тими самими числами в іншому порядку мають однакові діаграми.
4. **Кількість стовпчиків або секторів** дорівнює кількості різних значень. Якщо їх дуже багато, значення групують, і виходить гістограма.
5. **Histogramm: пропорційна площа, а не висота.** Висота = (відносна частота) ÷ (ширина інтервалу). Сума площ дорівнює 1, але сума висот не обов'язково.
6. **Типова задача на гістограму:** порахувати, скільки значень у кожному інтервалі, поділити на n, а потім поділити на ширину інтервалу. Наприклад, відносна частота 0,3 при ширині 2 дає висоту 0,15.
7. **Вибір інтервалів сильно впливає на картинку.** Занадто широкі інтервали ховають структуру, вузькі її показують (приклад з діамантами).
8. **Масштабування x → 3x.** У Balkendiagramm і Kreisdiagramm змінюються лише підписи, а висоти й сектори ті самі. У гістограмі це тільки при пропорційно збільшених інтервалах, але тоді змінюється також і висота (ширина ×3, висота ÷3).
9. **Streudiagramm:** кожен рядок таблиці це одна точка (x_{i,a}, x_{i,b}). Показує зв'язок між двома величинами. Хмара вгору вправо означає позитивну кореляцію. Ознаку з третього стовпця (наприклад, стать) показують кольором або символом.
10. **Точок може бути менше за n:** якщо значення повторюються, точки лягають одна на одну.
11. **Transformation** (log, √, x², 1/x, тотожна f(x)=x) допомагає, коли кілька величезних значень «ламають» масштаб. Після log(x) і log(y) прихована залежність стає видимою (приклад: площа й населення країн).
12. **Jitter-Diagramm:** до координат додають малі випадкові зміщення, щоб точки не лежали одна на одній. Його використовують, коли значення цілі й повторюються (приклад з циліндрами й MpG).
13. **Трусити потрібно якомога менше координат,** бо кожне трусіння спотворює дані. Якщо потрусити обидві координати, точки менше накладаються, але точні значення окремого об'єкта прочитати вже не можна, тож графік менш інформативний (завдання 1).
14. **Box-Diagramm** у цьому розділі лише згадується, її розбирають у розділі 5.2 (потрібен квантиль).
15. **Задачі, які можуть бути на іспиті:** відновити вектор за діаграмою (завдання 4, 9), знайти розмірність вектора (сума абсолютних висот), обрати гістограму за таблицею частот (завдання 6), порахувати висоти гістограми (завдання 5), побудувати діаграми для заданого вектора (завдання 10).

## Kapitel 4

1. Дискретна: **таблиця**, сума = 1, ймовірність події = сума рядків.
2. Неперервна: **крива**, площа = 1, ймовірність події = площа.
3. Для неперервної **P(X = x) = 0**. Для дискретної P(X = x) = p(x).
4. p(x) ≤ 1 завжди, а щільність f(x) може бути > 1.
5. Bin(n,p) — кількість успіхів у n незалежних спробах. Bin(1,p) — це те саме, що Bernoulli(p).
6. Функція ймовірностей: усі числа ≥ 0 **і сума = 1** (перевіряй обидві умови).
7. Дискретна: P(X = x) = p(x), а подію рахуєш додаванням рядків таблиці.
8. Неперервна: P(X = x) = 0, а “≤” і “<” однакові.
9. Щільність f(x) може бути > 1, p(x) ніколи.
10. Ймовірність для неперервної величини = первісна в b мінус первісна в a.
11. Значення щільності в точці (як f(1/4) у завданні 6) не є ймовірністю.
12. Bin(n, 1/2) симетричний, а не рівномірний (окрім n = 1).

## Kapitel 5

1. Функція розподілу: **F(t) = P(X ≤ t)**.
2. P(X > t) = 1 − F(t); P(a < X ≤ b) = F(b) − F(a).
3. Дискретна: F(t) = сума p(x) для x ≤ t, графік сходовий, стрибки в точках з p > 0.
4. Неперервна: F(t) = інтеграл щільності, стрибків немає, F′ = f.
5. F повністю визначає розподіл: однакові F означає однаковий розподіл.
6. Емпірична F̂(t) = (кількість xᵢ ≤ t) / n; це частка даних, що не перевищують t.
7. F̂ завжди сходова, значення від 0 до 1, не залежить від порядку даних.
8. Висота стрибка F̂ у точці = (кількість повторів)/n.
9. Квантиль: **Q(α) = min{t : F(t) ≥ α}**, найменше t, для якого F(t) ≥ α.
10. Для неперервної F: F(Q(α)) = α; для стандартного нормального Q = Φ⁻¹.
11. Емпіричний квантиль: нижній квартиль α = 0.25, медіана α = 0.5, верхній квартиль α = 0.75, дециль α = 0.1 і 0.9.
12. Формула: Q̂(α) = x₍ᵢ₎, якщо i−1 < nα ≤ i (рахуємо nα, округлюємо вгору до i, беремо i-те значення).
13. IQR = Q(0.75) − Q(0.25).
14. Box-plot: ящик від Q(0.25) до Q(0.75), лінія в ящику = медіана.
15. Вуса: до крайніх точок, що лежать у межах Q(0.25) − 1.5·IQR … Q(0.75) + 1.5·IQR.
16. Усе поза межами 1.5·IQR це викиди (окремі крапки).
17. Типове завдання: за вектором даних впорядкувати, побудувати F̂ або таблицю, знайти квартилі та IQR, обчислити межі вусів і знайти викиди.

## Kapitel 6

1. Mittelwert та Erwartungswert: центр ваги; E(X) = Σ x·p(x) або ∫ x·f(x)dx.
2. Лінійність: E(aX+b) = aE(X)+b, E(X+Y) = E(X)+E(Y). Працює лише для лінійних функцій.
3. Var(X) = E((X−E X)²) = E(X²) − (E X)².
4. Var(aX+b) = a²Var(X); b зникає, a у квадраті.
5. Sd = √Var, одиниці ті самі, що й у даних.
6. 1-й момент це сподівання, 2-й центральний момент це дисперсія.
7. Lagemaße (середнє, медіана, мода) показують центр; Streuungsmaße (Sd, IQR, відхилення) показують розкид.
8. Median та IQR стійкі до викидів, Mittelwert та Sd ні.
9. Schiefe = 0 для симетричних; > 0 правий хвіст довший; < 0 лівий хвіст довший.
10. Wölbung = 4-й центр. момент / Var²; Exzess = Wölbung − 3; для N(0,1): 3 і 0.
11. Таблицю E і Var для B(p), Bin, U[0,1], N, t треба знати напам'ять.

## Kapitel 7

1. Статистична «навчальна машина» (середнє арифметичне) має дві властивості: з ростом n вона точнішає (закон великих чисел), і її неточність можна виміряти (ЦГТ, бутстреп).
2. Ідентично розподілені: однаковий розподіл, тому збігаються й усі моменти.
3. Незалежні: E(g(X)h(Y)) = E(g(X))E(h(Y)) для **всіх** функцій g, h.
4. Некорельовані: лише E(XY) = E(X)E(Y), без функцій.
5. Незалежні ⇒ некорельовані, але **не навпаки**.
6. i.i.d. = незалежні й ідентично розподілені.
7. Незалежні нормальні: X+Y ~ N(μ_X+μ_Y, σ²_X+σ²_Y). Дисперсії додаються лише для незалежних.
8. aX+b ~ N(aμ+b, a²σ²).
9. Маркова (X ≥ 0): P(X > ε) ≤ E(X)/ε.
10. Чебишова: P(|X−E(X)| > ε) ≤ Var(X)/ε². Виводиться з Маркова заміною X на (X−EX)².
11. Schätzer: оцінювач, формула з даних (напр. X̄ₙ). Schätzfehler: X̄ₙ − μ.
12. E(X̄ₙ) = μ і Var(X̄ₙ) = σ²/n. Другу формулу дає незалежність: усі члени поза діагоналлю дорівнюють 0.
13. Закон великих чисел: P(|X̄ₙ − μ| > ε) → 0. Це збіжність за ймовірністю (→ᵖ).
14. Закон великих чисел не каже, наскільки велика похибка при конкретному n.
15. Наслідки закону великих чисел: p̂ₙ(w) →ᵖ p(w) (частота → ймовірність) і F̂ₙ(t) →ᵖ F(t) (емпіричний розподіл → справжній).
16. ЦГТ: (√n/σ)(X̄ₙ − μ) →ʷ N(0,1). Практично: P(X̄ₙ − μ ≤ t) ≈ Φ(√n·t/σ).
17. Закон великих чисел: похибка → 0, розподіл тривіальний. ЦГТ: похибку множимо на √n, і виходить нетривіальна нормальна форма.
18. Похибка має порядок 1/√n: щоб зменшити її вдвічі, потрібно вчетверо більше даних.
19. Бутстреп: з x₁,…,xₙ тягнемо n значень **із поверненням**, рахуємо θ̂ₙ*ʲ − θ̂ₙ, повторюємо m разів, будуємо емпіричний розподіл цих похибок.
20. Бутстреп працює для будь-якої характеристики (медіана, дисперсія…), а ЦГТ у цьому розділі розглядається для середнього. Результат бутстрепа випадковий.
21. Типова задача: P(|X̄ₙ − μ| ≤ t) ≈ 2Φ(√n·t/σ̂) − 1, де σ̂² замінює невідому σ².

## Kapitel 8

1. Незміщена: 𝔼(θ̂) = θ. Конзистентна: θ̂ → θ при n → ∞.
2. Дисперсія: ділимо на **n−1** (незміщена), а ділення на n дає зміщену оцінку.
3. Незміщена + Var → 0 = конзистентна.
4. Нормальна апроксимація: ℙ(μ̂ − μ ≤ t) ≈ Φ(√n·t/σ̂).
5. Довірчий інтервал: μ̂ ± (σ̂/√n)·квантиль. Для 95% квантиль ≈ 1.96.
6. Нормальні дані → t-розподіл з n−1 ступенями свободи, і інтервал точний.
7. Менше α → довший інтервал.
8. Тест: H₀ (немає ефекту) проти H₁, статистика T, критичне c, порівняти.
9. α = ймовірність помилки 1-го роду (відкинути правильну H₀).
10. Лівостороння: квантиль α. Правостороння: 1−α. Двостороння: 1−α/2 з |μ̂ − μ₀|.
11. Більше α → H₀ відкидається легше.
12. «Не відкинули H₀» ≠ «H₀ доведена».

## Kapitel 9

1. Kovarianz: Cov(x,y) = xy̅ − x̄·ȳ, додатна = «разом ростуть», від'ємна = «одне росте, інше падає».
2. Cov залежить від масштабу (правило ac), тому як міра зв'язку не годиться.
3. Corr = Cov / √(Var·Var), завжди між −1 і 1, масштаб не впливає (тільки знак).
4. Corr = 0 означає «немає лінійного зв'язку», але нелінійний може бути.
5. Scheinkorrelation: зв'язок через третю змінну (стать → дохід і взуття).
6. Регресія: y ≈ α̂ + β̂x, де β̂ = Cov(x,y)/Var(x), α̂ = ȳ − β̂x̄.
7. Для регресії достатньо п'яти середніх: x̄, ȳ, xx̅, yy̅, xy̅.
8. Residuum = yᵢ − ŷᵢ (реальне мінус передбачене); МНК мінімізує суму квадратів залишків.
9. R² = частка поясненої дисперсії = Var(ŷ)/Var(y); з однією змінною R² = Corr(x,y)².
10. R² = 0,81 означає «81 % мінливості пояснено».
11. Anscombe: однаковий R² не гарантує, що пряма підходить, тож завжди малюй графік.
12. PCA: стандартизуємо, знаходимо довгу вісь еліпса, її проєкція дає фактор fᵢ.
13. Довгий тонкий еліпс дає R² ≈ 1, коло дає R² ≈ 0.
14. PCA знаходить фактор, але інтерпретувати його має людина.
15. Регресійна пряма положистіша за PCA-пряму.
-------------------------------------------------------------------------
1. Cov = xy̅ − x̄·ȳ. Зсув Cov не міняє, множення на a·c міняє Cov у a·c разів.
2. Corr завжди між −1 і 1: якщо в тесті є «1,9» або «−1,9», це хибно.
3. Corr(ax+b, cy+d) = sign(ac)·Corr: масштаб скорочується, лишається лише знак.
4. Великий Cov нічого не доводить, дивись лише на Corr.
5. Var(x+y) = Var(x) + Var(y) + 2Cov. Без 2Cov формула хибна.
6. β̂ = Cov/Var(x), α̂ = ȳ − β̂x̄ (бери неокруглене β̂).
7. R² ≥ 0 завжди, і R² = Corr(x,y)² для однієї змінної x.
8. R² = Var(ŷ)/Var(y) — «частка поясненої мінливості».
9. Малий R² означає «немає сильного **лінійного** зв'язку», а не «немає зв'язку взагалі».
10. Регресійна пряма положистіша за PCA-пряму.
11. Незалежні ⇒ некорельовані, але **не навпаки** (задача 15b).
12. Регресія через нуль: b = xy̅/xx̅.


## Kapitel 10

1. Міра нерівності = розсіювання / центр, тому не залежить від валюти.
2. Sd(x)/x̄ проста, але її максимум √(n−1) залежить від n, тому для порівняння груп не годиться.
3. Крива Лоренца L(t): яку частку доходу мають найбідніші t·100%. Сортуй за зростанням.
4. Крива Лоренца завжди між діагоналлю L₁ (всі рівні) і «кутом» L₀ (один має все).
5. Gini κ = (площа між L₁ і L) / (площа між L₁ і L₀).
6. κ = 0 означає повну рівність, κ = 1 означає, що один має все. Завжди 0 ≤ κ ≤ 1.
7. У формулі κ чисельник містить i·x₍ᵢ₎ (відсортовані значення з номерами), а знаменник звичайну суму.
8. κ′ = κ·(n−1)/n. Різниця суттєва лише для малого n.
9. Закон Бенфорда: перша цифра 1 найчастіша (≈30%), 9 найрідша (≈5%); p(z) = log₁₀(1 + 1/z).
10. Бенфорд працює, коли дані охоплюють кілька порядків величини (log₁₀ X рівномірний).
11. Застосування: виявлення підроблених даних. Надто рівномірні перші цифри означають підозру.
12. Вектор даних це випадкова величина з рівноймовірним вибором елемента, тому формули для даних є окремими випадками формул для випадкових величин.
13. Var(x) = ‖x − x̄ι‖²/n: дисперсія це квадрат відстані між x і його проєкцією x̄ι, поділений на n.
14. x̄ι і x − x̄ι ортогональні (прямокутний трикутник).
15. Cor(x,y) = косинус кута між залишками, тому лежить між −1 і 1.
16. Регресія = ортогональна проєкція y на площину(ι, x); R² = Var(ŷ)/Var(y).
