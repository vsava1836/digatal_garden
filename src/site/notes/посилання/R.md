### Перші команди (те, що вже зустрічається в розділах 1–3)

r

```r
x <- c(158, 182, 179, 161, 183, 181)   # створити вектор даних (Beispiel 2.2)
mean(x)                                 # середнє арифметичне
length(x)                               # кількість значень n
sum(x)                                  # сума
sort(x)                                 # впорядкувати
table(c(4,4,2,2,2,3,1))                 # таблиця значень з абсолютними частотами
hist(x)                                 # гістограма
boxplot(x)                              # box-діаграма
plot(x, y)                              # діаграма розсіювання (двох векторів)
```

Кілька важливих правил:

- `<-` означає «присвоїти» (`x <- 5`).
- Десяткова крапка, а не кома (як і в скрипті: 0.5).
- `#` це коментар, R його ігнорує.
- Довідка по команді: `?mean`.
