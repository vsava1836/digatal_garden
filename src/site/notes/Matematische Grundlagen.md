### Завдання 8: середнє через вектори

У скрипті вектор із одиниць позначено **ι = (1, …, 1)ᵀ**. Тоді ιᵀx = x₁ + … + xₙ. Отже:
$$\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i = \frac{1}{n}\,\iota^\top x$$
### Завдання 9: довести, що (1/n) Σ(xᵢ − x̄) = 0

$$\frac{1}{n}\sum_{i=1}^n (x_i - \bar{x}) = \frac{1}{n}\sum_{i=1}^n x_i - \frac{1}{n}\sum_{i=1}^n \bar{x} = \bar{x} - \frac{1}{n}\cdot n\bar{x} = \bar{x} - \bar{x} = 0$$

Ідея: x̄ є константою, тому сума n однакових доданків x̄ дорівнює n·x̄. Тобто **відхилення від середнього в сумі дають нуль**: додатні й від'ємні компенсують одне одного. Це важлива властивість середнього, вона ще знадобиться.

## формула щільності 

$f(x) = 1 / (σ · √(2π)) · e^( −(x − μ)² / (2σ²) )$

- **x** це точка, де ми рахуємо значення щільності.
- **μ** (читається «мю») це **центр** розподілу, там, де «горб» найвищий.
- **σ** (читається «сигма») показує, **наскільки розплюснутий** горб. Менше σ дає вузький високий горб, більше σ дає широкий низький.
- **σ²** це дисперсія. Саме її пишуть у N(μ, σ²). У формулі стоїть σ (без квадрата) перед коренем, а σ² у знаменнику в показнику.
- **π** ≈ 3.14159 (те саме число, що в колі).
- **e** ≈ 2.718 (стале число, воно «записане» на калькуляторі як eˣ).

## Формула ймовірності біноміального розподілу

$p(k) = C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ, для  k = 0, 1, 2, …, n$

- **pᵏ** це ймовірність, що в k конкретних спробах був успіх (p перемножене k разів).
- **(1 − p)ⁿ⁻ᵏ** це ймовірність, що в решті n − k спроб успіху не було.
- **C(n, k)** це кількість способів вибрати, **в яких саме** спробах із n були успіхи. Читається «n по k».
- **C(n, k) = n! / (k! · (n − k)!)**.

## Kapitel 8

**Незміщеність і конзистентність**

1. Незміщений: 𝔼(θ̂ₙ) = θ
2. Конзистентний: θ̂ₙ →ᴾ θ, тобто ℙ(|θ̂ₙ − θ| > ε) → 0
3. Критерій: незміщений + Var(θ̂ₙ) → 0 ⟹ конзистентний (через Чебишева)

**Оцінювачі**  
4. μ̂ₙ = (1/n)·ΣXᵢ (незміщений, конзистентний), Var(μ̂ₙ) = σ²/n  
5. σ̃ₙ² = (1/n)·Σ(Xᵢ − μ̂ₙ)² (зміщений), 𝔼(σ̃ₙ²) = σ²·(n−1)/n  
6. σ̂ₙ² = (1/(n−1))·Σ(Xᵢ − μ̂ₙ)² = (n/(n−1))·σ̃ₙ² (незміщений, конзистентний)  
7. σ̂ₙ = √(σ̂ₙ²) (конзистентний для σ)

**Нормальна апроксимація похибки**  
8. ℙ(μ̂ₙ − μ ≤ t) ≈ Φ(√n·t / σ̂ₙ)

**Довірчі інтервали для μ (рівень 1−α)**  
9. Нормальний: μ̂ₙ ± (σ̂ₙ/√n)·Φ⁻¹(1−α/2)  
10. t-інтервал (нормальні Xᵢ): μ̂ₙ ± (σ̂ₙ/√n)·F⁻¹ₙ₋₁(1−α/2)  
11. Симетрія квантилів: Φ⁻¹(α/2) = −Φ⁻¹(1−α/2)  
12. Корисні квантилі: Φ⁻¹(0.95) ≈ 1.645; Φ⁻¹(0.975) ≈ 1.96; Φ⁻¹(0.995) ≈ 2.576

**Тести для μ**  
13. Рівень значущості: ℙ(відкинути H₀ | H₀) = α  
14. Лівосторонній: відкидаємо, якщо μ̂ₙ − μ₀ ≤ (σ̂ₙ/√n)·Φ⁻¹(α)  
15. Правосторонній: відкидаємо, якщо μ̂ₙ − μ₀ > (σ̂ₙ/√n)·Φ⁻¹(1−α)  
16. Двосторонній: відкидаємо, якщо |μ̂ₙ − μ₀| > (σ̂ₙ/√n)·Φ⁻¹(1−α/2)  
17. Альтернативна форма: T′ = (√n/σ̂ₙ)·(μ̂ₙ − μ₀), c′ = Φ⁻¹(·) (або F⁻¹ₙ₋₁(·))  
18. Power = 1 − ℙ(не відкинути H₀ | H₁)

## Kapitel 9

**Коваріація**

- Cov(x,y) = (1/n)Σ(xᵢ − x̄)(yᵢ − ȳ)
- **Cov(x,y) = xy̅ − x̄·ȳ** (для задач)
- Cov(X,Y) = E(XY) − E(X)E(Y)
- Cov(X,X) = Var(X)
- Cov(aX+b, cY+d) = ac·Cov(X,Y)
- Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y)
- Незалежні (некорельовані) ⇒ Cov = 0

**Кореляція**

- **Corr(x,y) = Cov(x,y) / √(Var(x)·Var(y))**
- Corr(ax+b, cy+d) = sign(ac)·Corr(x,y)
- −1 ≤ Corr ≤ 1

**Регресія (МНК)**

- **β̂ = Cov(x,y)/Var(x) = (xy̅ − x̄ȳ)/(xx̅ − x̄²)**
- **α̂ = ȳ − β̂·x̄**
- Нормальні рівняння: ȳ − α̂ − β̂x̄ = 0 і xy̅ − α̂x̄ − β̂xx̅ = 0
- Підігнане значення: ŷᵢ = α̂ + β̂xᵢ
- Залишок: r̂ᵢ = yᵢ − ŷᵢ
- Теоретична версія: b* = Cov(X,Y)/Var(X), a* = E(Y) − b*E(X)

**Коефіцієнт детермінації**

- **R² = Corr(y, ŷ)²**
- **R² = Var(ŷ)/Var(y)**
- **R² = Corr(x,y)² = Cov(x,y)² / (Var(x)Var(y))** (лише одна змінна x)
- 0 ≤ R² ≤ 1

**PCA**

- Стандартизація: x⁽ˢ⁾ = (x − x̄)/√Var(x)
- Точка ≈ fᵢ·v⁽¹⁾
- Мінімізується Δ(c) = (1/n)Σgᵢ²
